
# 📊 Machine Learning Projects

A curated set of **Python Jupyter Notebook projects** exploring fundamental Machine Learning concepts, algorithms, and real-world datasets.
These notebooks illustrate practical implementations of key ML techniques using **scikit-learn**, **pandas**, and other Python tools to solve classification, regression, and clustering problems.

---

## 🧠 What This Repository Contains

This repo includes hands-on notebooks on various ML topics:

* 📌 **K-Nearest Neighbors (KNN)** — Classification approaches
* 📊 **Regression Tasks** — Housing price prediction workflows
* 🚑 **Healthcare Analytics** — E.g., heart disease prediction
* 🍷 **Wine Quality Analysis** — Regression & classification examples
* 🧪 **Credit Card Fraud Detection** — Real-world anomaly detection
* 🚢 **Titanic Survival Prediction**
* 🌀 **Unsupervised Learning (K-Means Clustering)**
* ✨ Feature selection and RFE techniques
* 📂 Dataset samples in `.csv` format

*(Notebooks use standard ML libraries and techniques for learning and experimentation.)* ([GitHub][1])

## 🛠️ Technologies & Libraries

This repository relies on:

* 🐍 **Python**
* 📓 **Jupyter Notebook** files for interactive experimentation

## 🚀 Getting Started

To run these notebooks locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/mohankrishna7276/Machine-Learning.git
   cd Machine-Learning
   ```

2. **Install dependencies**

   ```bash
   pip install numpy pandas scikit-learn matplotlib seaborn notebook
   ```

3. **Launch Jupyter Notebook**

   ```bash
   jupyter notebook
   ```

4. Open any `.ipynb` file and start exploring!
